Privacy Policy

Untold Stories Uploader (last updated 26 November 2026)

This tool is used only by the owner of the YouTube channel "Untold Stories" to manage that same channel. It uses the YouTube Data API and YouTube Analytics API to upload the owner's own videos, set titles, descriptions and thumbnails, add videos to playlists, post the channel's own comments and read the channel's own statistics.

What data is used

Only data of the owner's own YouTube channel, accessed with the owner's permission through Google OAuth. No data of any other person is collected, stored, sold or shared.

Storage

The OAuth access token is stored privately by the owner and is used only to perform the actions above. Channel statistics may be kept in the owner's private logs to plan future videos.

YouTube and Google

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. Access can be revoked at any time at Google account permissions.
